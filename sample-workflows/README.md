# Sample Workflows

This folder contains sample ComfyUI workflow JSON files used for testing and demonstrating EasyComfyUI.

The sample workflows are not created by this project. They are included for viewer testing, learning, and compatibility demonstration. Please refer to the original Civitai pages for authorship, licensing, required models, and setup instructions.
