# Changelog

## [0.1.0-alpha] - 2025-05-10

### Added
- Initial alpha release
- Android WebView-based workflow viewer
- Web-based workflow viewer (open `web-viewer/index.html` in any browser)
- Workflow JSON file loading via file picker or drag-and-drop
- Node graph rendering with zoom, pan, and fit-to-view
- Node search with highlight and jump-to-next
- Markdown link rendering in node descriptions
- Widget value display (text, number, boolean, combo, etc.)
- Slot (port) connection visualization
- Group rendering
- Collapsed node rendering
- Node source classification (built-in, custom, missing)
- Workflow history
- Nodes source summary panel
- About panel
- Adaptive app icon
- Alpha APK build for real-device installation
